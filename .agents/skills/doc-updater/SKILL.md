# Tepora V3 documentation updates

Use this skill for requested documentation updates or changes to setup, commands, behavior and directory structure.

1. Read the affected code and current documentation before editing.
2. Update root `README.md`, `docs/CHANGELOG.md`, relevant guides under `docs/`, and canonical V3 documents under `Tepora-v3/docs/` as appropriate.
3. Keep current release wording at `3.0.0-beta.11`. Distinguish fixture tests, package builds, real model acceptance and unverified behavior.
4. Preserve the protected/legacy-host distinction, exact permission requirements, data scope and remaining implementation limits.
5. Fix local links and command examples. Earlier revisions belong in Git history; do not restore old application archives.
6. Follow the user's authorized scope. A request to update documents authorizes the corresponding reversible edits; request clarification only for a material unresolved change of scope.
