# Tepora V3 beta.11 ユーザーガイド

## 使い始め

Node.js 22.16.0以上を用意し、リポジトリのルートで `npm start` を実行します。Windowsは `start.cmd`、macOSは `start.command` から起動できます。AIを使わない画面確認は `npm run preview:build` で生成したHTMLを開きます。

上部の「AIを接続」（または「設定 → AIとの接続」）で稼働中のローカルサーバーを探し、モデル接続を確認します。外部プロバイダーを使う場合は送信先と通信許可を設定します。モデル本体やOSの実行環境は自動導入されません。

## 会話と仕事

ホームではキャラクターの下の入力欄から、ひとつの継続した会話を続けます。会話の全体は「会話の履歴」（ほかの画面では「会話」）で開きます。「設定 → キャラクター → 人格と口調」でキャラクターと作業担当の名前・指示を別々に保存できます。キャラクターの口調・呼び名・話しかけ方もここで決めます（口調は画面の一言と、AIへの話し方の指示にだけ使います）。設定変更は新しい処理に適用され、進行中の仕事の人格は固定されます。

会話から仕事を任せると、別ワーカーが非同期に実行します。仕事の詳細や成果物を開いても入力先は同じキャラクターです。進捗・結果には作業担当と状態が表示されます。「回答する」は指定されたワーカーの質問に答える操作です。通常の会話や質問への回答だけではツール操作を承認しません。

会話とワーカーの接続先が異なる結果は自動で再送されません。仕事の詳細にある「引用を会話に共有」で内容・範囲・送信先を確認してください。

承認・作業担当の質問・確認待ちの結果・止まった仕事・提案は、上部の「あなたの番」に集まります（ホームでは、キャラクターのそばの橙色のランプからも開けます）。画面の前に人がいない間は、承認が必要な操作だけを保留し、ほかの作業を続けます。あとで許可すると、許可した内容そのものを実行します。

許可は、承認の札にある印を押して行います。このPCでの実行や、費用がかかるかもしれない操作は、印を0.7秒ほど押し続けてください（途中で離すと何も起きません）。それ以外は一度押せば許可されます。キーボードや支援技術では、印を一度押すと待機状態になり、4秒以内にもう一度押すと許可されます。「見送る」はそのまま押せます。

## キャラクターの姿

「設定 → キャラクター → 姿を作る」で、ホームのキャラクターの見た目を選びます。初めの姿は「しろ・改」です。体（しろ・改・灯守・円相・小箱・狐火・蛍・苔玉）、素材（色）、灯りの色と形、顔、耳、小物（季節・好み）、大きさと動きを変えられ、選ぶとすぐ保存されます。プレビューは、下の選択肢を動かしても見えたままです。「さいころ」はおまかせの組み合わせ、「前に戻す」「既定に戻す」でやり直せ、「姿を書き出す」「読み込む」で設定を持ち運べます（ファイルや許可は含まれません）。しろ・改は「質感」で「立体」を選ぶと、3Dで表示されます。琥珀色は「あなたの番」の色なので、灯りには選べません。

今までのキャラクターも、そのまま使えます。「持ち込む」から、3Dモデル（VRM 1.0 / 0.x）、画像（1枚）、画像セット（気分ごとの絵。口を開けた絵も使えます）、メッシュアバター（mesh-avatar-studio の projects フォルダ）を選んでください。ファイルはこのPCにだけ保存され、中身を確認してから使います。VRM に書かれた作者と利用条件は、持ち込んだものの一覧に表示されます。表示できないときは、しろ・改で表示して理由をお知らせします。OSの「視差効果を減らす」がオンのときは、動きを止めます。

姿と口調は別々の設定です。どの姿にも、どの口調を組み合わせても構いません。

## ホームと待機画面

ホームでは、キャラクターの返事が字幕のように表示されます。進めている仕事はキャラクターのそばの小さな灯りで、確認が必要なことは橙色のランプひとつで知らせます。灯りを押すとその仕事が、ランプを押すと「あなたの番」が開きます。背景の部屋では、時刻と天気に合わせて窓の光が動きます。日付の下には七十二候と、天気が一行で表示されます。待機画面から戻ると、キャラクターが留守のあいだのできごとを伝えます。

操作のない時間が続くと（時間は「設定 → ホームと待機画面」で選べます）、どの画面からでも待機画面に切り替わります。スクリーンセーバーと同じように、キーを押す・触れる・クリックする・マウスを大きく動かすと、元の画面に戻ります。文章を入力している間や、パネルを開いている間は始まりません。夜は、昼の色を暗くするのではなく、行灯のような暗い配色になります。「画面をつけたままにする」を入れると、待機画面のあいだ画面が消えません（対応している環境のみ）。

壁紙は「部屋」「無地」「ゆらぎ」「星空」「写真」から選べます。

デジタル写真立てにするには、「設定 → ホームと待機画面 → 写真立て → 写真を管理」で写真を追加します。写真はこのPCに保存され、外へは送られません。大きな写真は、画面に十分な大きさへ縮小されます。切り替えの間隔（10秒〜1時間）、順番（シャッフル・追加順）、表示（画面いっぱい・全体・額装）、動き、時計（なし・小さく・大きく）、「つくった画像」を混ぜるかどうかを選べます。「画面の表示」メニューの「写真立てにする」を選ぶと、全画面でそのまま始まります。共有表示では、写真は表示されません。

## 成果物と添付

成果物は版を保持し、更新への追従・版の固定・編集・書き出しができます。仕事の受け入れは内容の確認後に行います。ワーカーが完了と報告しても、内容の正しさが独立に検証されたことにはなりません。

任意コード実行の出力はまず候補になります。実行境界画面で正確な内容と元の版を確認して取り込みます。これは仕事全体の受け入れとは別の操作です。

UTF-8テキストとPNG/JPEGを添付できます。PDF・Office文書の取り込みは未対応です。

## 実行と通信

初期設定は `protected` です。会話と組み込み機能はDockerなしで使えます。任意コードには事前導入・承認したNode対応Dockerイメージが必要です。コンテナにはネットワーク、ホストの原本、認証情報を渡しません。

ホストCLI・Codex・MCP・PC操作・モデル起動連携は `legacy-host` の明示的な確認が必要です。このモードはOSで隔離されず、アプリのソースやバックアップへアクセスできる可能性があります。切り替え前に仕事と既知のホスト処理を停止してください。

オンライン・指定LAN接続先・完全オフラインは通信の設定です。実行モードを切り替えても通信や操作の許可が自動で増えることはありません。

## 音声・生成・記憶

「設定 → 声・画像・意味検索 → 能力の接続」で音声・画像・動画・埋め込み等の接続先を個別に設定します。最新の返事の「読み上げる」は明示操作です。「つくったもの」では送信する内容と接続先を確認して生成します。受付済みの生成と完成した生成は区別されます。

記憶の意味検索は接続した埋め込みサービスを使います。外部への記憶共有には確認が必要です。既存の記憶は新しいキャラクターやワーカーへ自動挿入されません。

V2のデータは自動移行されません。詳細な制限と保存範囲は[beta.11説明](../Tepora-v3/docs/BETA11.md)と[README](../Tepora-v3/README.md)を参照してください。
