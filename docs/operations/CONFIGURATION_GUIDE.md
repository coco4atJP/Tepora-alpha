# Tepora V3 beta.11 設定ガイド

上部の「AIを接続」（または「設定 → AIとの接続」）で既存のローカル推論サービスを接続します。会話・作業・画像理解・音声編集などのプロバイダーを役割ごとに設定し、API形式、モデル、接続先を確認します。外部への送信は個別の許可が必要です。

APIキーは接続先に紐づくメモリ上の値または環境変数への参照として扱います。接続先を変えた場合はキーを再設定します。モデル一覧のメタデータは動作検証やインストール許可ではありません。

## 実行境界

「設定 → 仕事の実行 → 実行環境」の初期値は `protected` です。組み込みツールはDockerなしで使えます。任意コードには、事前導入したNode対応イメージの `repository@sha256:...` を入力し、承認します。利用可否の確認はイメージの検査で、隔離の実動作試験ではありません。

`legacy-host` はホストCLI・MCP・Codex・PC操作・モデル起動連携を有効にする明示設定です。ホストのファイルやバックアップをOSで隔離しません。仕事と既知のホスト処理を停止してから切り替えてください。

## 通信と能力

オンライン・指定LAN接続先・完全オフラインは実行境界とは独立しています。指定LANは登録・固定した推論接続先のみを許可します。外部のローカルサーバーが通信を転送することをOS全体で制御する機能ではありません。

「設定 → 声・画像・意味検索 → 能力の接続」で判断、埋め込み、TTS、画像・動画生成の接続先を独立設定できます。MCP設定の取り込みは起動と別です。接続にはlegacy-hostと既存の通信・操作許可が必要です。Codexのサインインも同じ実行制限を受けます。

## 保存先と環境変数

ソース版の標準保存先:

- Windows: `%LOCALAPPDATA%/Tepora/v3`
- macOS: `~/Library/Application Support/Tepora/v3`
- その他: `~/.local/share/tepora-v3`

`TEPORA_DATA_DIR` で変更できます。`TEPORA_PORT` はサービスのポートを指定し、既定は空きポートです。Tauri版はホストが指定するアプリ専用データ領域を使うため、ソース版と同じ場所とは限りません。

SQLiteの保存内容は暗号化されていません。V2の `config.yml`・人格・プロフィールの自動移行はありません。旧データを削除したり直接上書きしたりしないでください。

モデル起動の条件は[ランタイム接続](../../Tepora-v3/docs/RUNTIME-LAUNCH.md)、詳しい実行境界は[beta.11説明](../../Tepora-v3/docs/BETA11.md)を参照してください。
